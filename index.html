Синхронизация через GitHub

1
Создайте GitHub токен
Нужен токен с правом gist. Нажмите ссылку — откроется форма с уже выставленными правами:
Открыть GitHub → Создать токен ↗
2
Вставьте токен
Токен хранится только в этом браузере — никуда не отправляется.
3
Нажмите «Сохранить» один раз
После этого данные будут синхронизироваться автоматически при каждом изменении. Точка ⬤ в шапке: жёлтая — идёт сохранение, зелёная — синхронизировано.
Открыть ↗
Важно: токен нужно ввести на каждом устройстве отдельно — он хранится только в браузере этого устройства. На каждом новом телефоне или компьютере: введите тот же токен + Gist ID → нажмите «⬇ Загрузить данные».
